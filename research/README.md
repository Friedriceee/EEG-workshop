# research/ — 文献与方法调研

## 怎么交

1. 每个人复制 `TEMPLATE.md`,改名为 `<你的名字>_<方法关键词>.md`,放在这个文件夹里。
2. 论文 PDF 或链接写进文件里,**不要把 PDF 本身提交到仓库**(体积大)。
3. **周一(11/9)之前**:在群里发一段文字,只说三件事——你想探索哪个方法、依据哪篇论文、下周准备做什么实验。
4. 下周(11/10–11/14)做实验;11/14 组会汇总。

## 规则

- 每个人选**一个**方法,开会前互相看一眼,避免重复。
- 每条论文结论要**回到原文核对**,不要直接抄摘要里的数字。
- 论文里的提升是在它自己的数据上得到的;我们只有 10 个人、2655 段,结论要在我们的统一考试里重新验证。
- 每个方法都要回答两个问题:**能不能一个窗口一个窗口地做?能不能写进单个 `submission.py`?**
